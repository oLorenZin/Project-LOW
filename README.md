**LOW** é uma suíte de manutenção e otimização "All-in-One" escrita nativamente em Batch e PowerShell. Desenvolvido para gamers, power users e técnicos que desejam extrair o máximo de desempenho do hardware sem instalar softwares pesados de terceiros.

O script opera com uma interface CLI (Linha de Comando) estilo "Hacker/Alien", focada em velocidade e eficiência.

---

## 🔥 Funcionalidades Principais

O LOW oferece 19 módulos principais organizados em um grid de fácil acesso:

### ⚡ Desempenho & FPS
- **Otimização Visual:** Remove animações e efeitos desnecessários do Windows.
- **Modo Energia Ultimate:** Ativa planos de energia ocultos para performance máxima.
- **HPET & Latência:** Desativa o *High Precision Event Timer* para reduzir micro-stuttering.
- **Boot Rápido:** Remove o delay de inicialização de aplicativos e serviços.

### 🌐 Rede & Conectividade
- **Otimização TCP:** Ajustes de registro para reduzir o Ping (TCP NoDelay, AckFrequency).
- **DNS Gamer:** Troca rápida para DNS Cloudflare (1.1.1.1) ou Google.
- **Wi-Fi Keys:** Recupera e exibe senhas de todas as redes Wi-Fi salvas no PC.

### 🛡️ Manutenção & Sistema
- **System Scanner:** Diagnóstico profundo (Saúde da Bateria, SMART do SSD, Histórico de Telas Azuis/BSOD).
- **Limpeza Total:** Remove arquivos temporários, Cache de Updates e **Shader Cache (NVIDIA/AMD)**.
- **Debloat:** Remove bloatware pré-instalado do Windows (Apps inúteis).
- **Backup Pessoal:** Salva automaticamente documentos e imagens na Área de Trabalho.

### 🔧 Avançado
- **Regedit (Avançado):** Aplica tweaks profundos (HAGS, Game Mode, Prioridade de CPU/GPU).
- **Notas Secretas (ADS):** Sistema de anotações criptografadas (Base64) salvas em fluxos ocultos (Alternate Data Streams) dentro do próprio script.

## 🚀 Como Usar
Não é necessário instalar nada. O script é "Portable".

Baixe o arquivo .bat da última release ou clique em Code > Download ZIP.

Clique com o botão direito no arquivo Project_LOW.bat.

Selecione "Executar como Administrador" (Necessário para aplicar alterações no sistema).

Siga as instruções na tela. Recomenda-se começar pela Opção 1 (Ponto de Restauração).

## ⚠️ Aviso Legal
Este software altera configurações do Registro do Windows e serviços do sistema. Embora tenha sido testado exaustivamente e inclua a criação de Pontos de Restauração:

Use por sua conta e risco.

Sempre faça um backup de seus dados importantes antes de executar ferramentas de otimização.
