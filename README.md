🚀 LOW - Limpeza e Otimizador do Windows
LOW é uma suíte de manutenção e otimização "All-in-One" escrita nativamente com uma arquitetura híbrida (Batch como iniciador blindado + PowerShell para a lógica). Foi desenvolvido para gamers, power users e técnicos que desejam extrair o máximo de desempenho do hardware de forma segura, sem precisar instalar softwares pesados de terceiros.

O script opera com uma interface CLI (Linha de Comando) ao estilo "Hacker/Alien", contando agora com recursos de simulação, execução em lote e monitoramento de hardware.

🔥 Funcionalidades Principais
O LOW oferece 19 módulos principais e comandos inteligentes organizados em um painel de fácil acesso:

⚙️ Execução Inteligente (NOVIDADE)
Seleção Múltipla: Execute várias tarefas de uma só vez, separando-as por vírgulas (Ex: 1,3,10).

[99] Quick Optimize: Um atalho de um clique para executar o "Top 5" de otimizações essenciais (Ponto de Restauração, Visual, Energia, Rede e Limpeza).

[D] Modo Dry-Run (Simulação): Testa o script sem aplicar nenhuma alteração real no sistema. Excelente para auditorias.

[L] Logs em Memória: Exibe um relatório completo no terminal de tudo o que foi alterado ou simulado durante a sessão atual.

⚡ Desempenho & FPS
Otimização Visual: Remove animações e efeitos desnecessários do Windows.

HUD de Hardware: Monitoramento de Temperatura da CPU / GPU e Uptime diretamente no cabeçalho.

Modo Energia Ultimate: Ativa planos de energia ocultos e otimiza o SSD com a funcionalidade TRIM (Optimize-Volume).

HPET & Latência: Desativa o High Precision Event Timer para reduzir o micro-stuttering em jogos.

🌐 Rede & Conectividade
Otimização TCP: Ajustes avançados de registro para reduzir o Ping (TCP NoDelay, AckFrequency, NetworkThrottling).

DNS Gamer: Troca rápida para DNS Cloudflare (1.1.1.1) ou Google.

Wi-Fi Keys: Recupera e exibe as senhas de todas as redes Wi-Fi salvas no PC.

🛡️ Manutenção Segura
System Scanner: Diagnóstico profundo (Saúde da Bateria, Erros de Drivers e Histórico de Telas Azuis/BSOD).

Limpeza Profunda: Remove lixo de sistema, Prefetch e limpa o Shader Cache (NVIDIA/AMD), resolvendo travamentos (stuttering).

Backup Inteligente: Copia PDFs e documentos para a Área de Trabalho (ignorando, por segurança, arquivos maiores que 100MB).

Proteção de Serviços: Avisos detalhados antes de desativar recursos vitais (Spooler de Impressão, acesso remoto RDP, etc.).

🔧 Avançado
[19] Regedit Ultimate: Aplica ajustes avançados em um só clique (HAGS / GPU Scheduling, Game Mode, Desativação do Bing na Pesquisa).

Notas Secretas (ADS): Sistema de anotações codificadas em Base64, salvas de forma invisível via Alternate Data Streams dentro do próprio script.

🚀 Como Usar
Não é necessário instalar nada. O script é 100% "Portable" e está blindado contra falhas de codificação.

Baixe o arquivo .bat da última release ou clique em Code > Download ZIP.

Clique com o botão direito do mouse no arquivo Project_LOW.bat.

Selecione "Executar como Administrador" (Necessário para aplicar alterações no registro e nos serviços).

Dica: Para executar o script sem as animações de texto (Modo Rápido), abra-o através do terminal usando Project_LOW.bat --fast.

Siga as instruções apresentadas na tela. Recomenda-se vivamente começar pela Opção 1 (Ponto de Restauração).

⚠️ Aviso Legal
Este software altera configurações profundas do Registro do Windows e serviços vitais do sistema. Embora tenha sido exaustivamente testado, validado para segurança e possua um modo de simulação (Dry-Run):

Utilize por sua conta e risco.

Faça sempre um backup dos seus dados importantes e crie um Ponto de Restauração antes de executar ferramentas de otimização em massa (como a Opção 19).
